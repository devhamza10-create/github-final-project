# Simple Interest Calculator

A Bash-based calculator that computes simple interest based on the principal amount, rate of interest, and time period.

## Project Details

This project is part of the Git and GitHub final project.

The calculator accepts the following inputs:

- Principal amount
- Rate of interest
- Time period

It then calculates simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100
